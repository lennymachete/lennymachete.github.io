How I get technical fast

At Elemental I was told it takes about six months before a new hire is really useful, because the lighting products are that technical. I had no lighting background. I was promoted in four.

  1. Build my own ramp kit before day one

    Before my first day I built a starter bundle: a product reference, customer segments, the math and formulas, and a field guide.

  2. Turn notes into tools

    My ramp notes became an onboarding guide and a one-screen field card. The training team adopted both for new hires.

  3. Use AI to learn, then check it

    I use AI to break down specs and product rules, then confirm against the real spec sheet before I rely on it.

  4. Do the volume

    500 quotes in four months. Reps are how a new language becomes normal.

The loop

The same five steps, whether it's a roof bid, a dispatch shift, a brand program, or a multi-zone quote.

  1. Read the source before touching anything

    Get every requirement out of what people actually sent or said. Write down what's missing and ask before building.

  2. Map it

    Turn the mess into a structure: what goes where, in what format, and what rule applies. The map is the plan.

  3. Build the system, and automate the repeat work

    Set it up the way people really work. Anything done three times becomes a checklist, a template, or a tool.

  4. Check it before it ships

    Validate against the source and against real conditions. Nothing goes out until it passes.

  5. Write it down and hand it off clean

    Document it while it's fresh, and get people comfortable using it, so the next person doesn't have to guess.

Why I call it a system

A checklist is a list. A system learns.

Every outcome is data

A rejection, a QC note, a missed detail. Each result goes back in and shapes the next version.

Every system has a memory

Logs, notes, trackers, the price guide. Memory is what lets a system adapt instead of repeat the same mistake.

AI makes it breathe

AI isn't just automation. It doesn't remember on its own; it works from what the system feeds it. So I build the memory and the feedback loop in on purpose, and the system keeps adjusting.
