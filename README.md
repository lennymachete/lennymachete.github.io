## How I work

- **I'm only as good as what I know.** I learn the work first, by doing it and by talking with the people who live it.
- **I take it apart.** I don't just get things. I break them down layer by layer until I understand them, then put them back together simpler.
- **Easy things get easy. Hard things get the time.** The tool takes the copying and pasting, so attention goes to catching what matters.
- **Run it until it breaks.** Every run teaches something. I fix it before anyone else relies on it.
- **I'm not here to disrupt. I'm here to improve.** I build around how the team already works.

## How I use AI

AI is only as good as the person using it. I use it three ways:

- **Automation:** the repeat work runs itself.
- **Augmentation:** it helps me break down a problem and think faster, and I check it against the source.
- **Agents:** scheduled agents do background work and report back. I review what they find.

I design each tool, set the rules, and test every run. AI writes most of the code from my direction. AI drafts and checks. A person signs off.
